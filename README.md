# 3-2 Excercises (Counting Chickens)

### Abstract

This repo is a clone of Oracle's chickens exercise split into two parts, requiring me to fill in the syntax for the two provided files with instructions.

### Implementations:

`Chickens01.java`: Focused on integer values; using three main variables across three different days of the week. Different scenario each day, giving an end result of 45 and 84 from the default values given by Oracle.

`Chickens02.java`: Uses `int` and `double` variables to calculate the daily average egg production, the expected production over 30 days, and the monthly profit based on the price per egg.
